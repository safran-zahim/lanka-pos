# Knowledge Base

This folder stores long-form technical knowledge for the Lanka POS workspace.

## Files

- `LANKA_POS_WORKSPACE_ARCHITECTURE_ANALYSIS.md`: Comprehensive architecture and request-flow mapping.

## Scope

- Feature inventory (backend + frontend)
- Linkage map (UI -> API -> controller -> DB)
- Technical specifications and constraints
- Request processing lifecycle
- Database verification snapshots and caveats

## Update Rule

Update this knowledge base when system behavior, architecture, routes, models, or processing flows change.

## Repository Convention Note

- Keep browser e2e test assets in `tools/testing/`.
- Keep process/readme documentation under `docs/` or `system-tracker/`, not inside application source folders.
