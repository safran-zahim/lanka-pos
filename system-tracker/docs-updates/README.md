# Documentation Updates

Use this folder to track documentation maintenance alongside code changes.

## Purpose

- Record what docs were updated and why.
- Track pending docs work.
- Keep docs updates auditable per day.

## Files

- `daily-doc-updates.md`: Chronological doc maintenance log.

## Workflow

1. After code changes, update technical docs if behavior changed.
2. Add an entry in `daily-doc-updates.md`.
3. Cross-reference the same change in `system-tracker/daily/YYYY-MM-DD.md`.
